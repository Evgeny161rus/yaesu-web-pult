# Темы оформления пульта

Пульт (`index.html`) имеет 3 темы («внешний вид»). Переключаются в настройках пульта:
**Настройки → Оформление пульта**. Выбор хранится в `localStorage` под ключом
`ftx1-appearance`.

От оформления отдельно настраиваются:

- **компоновка** — `ftx1-workspace`: `classic`, `dx`; панели в классике можно
  переставлять в режиме «Компоновка»;
- **размер кнопок** — `ftx1-density`: `normal`, `touch`.

Темы задаются CSS-переменными через атрибут `data-appearance` на `<html>`,
компоновка — `data-workspace`, размер — `data-density`.
Файлы: `web/app.css` (базовая), `web/appearance.css` (темы),
`web/dx.css` (DX-компоновка).

| ID | Название | Стиль |
|---|---|---|
| `original` | Тёмная | базовая тёмная, циановый акцент |
| `heritage` | Тёплая (Heritage) | «ламповая», янтарный LCD, углы 3px |
| `daylight` | Светлая | светлая, бирюзовый акцент, тени |

## Цвета

| ID | Фон | Панель | Текст | Акцент | LCD |
|---|---|---|---|---|---|
| `original` | `#0b0f14` | `#121820` | `#dbe5ef` | `#36c5f0` | `#9ff2ff` |
| `heritage` | `#141310` | `#211f19` | `#efe5d2` | `#efb65d` | `#ffcc78` |
| `daylight` | `#e9eef1` | `#ffffff` | `#192d36` | `#006879` | `#005364` |

Дополнительные смысловые цвета (у всех тем): `--ok` (зелёный), `--warn` (жёлтый),
`--tx` (красный, передача).

## Описание

- **original** — базовая тёмная тема из `app.css`, циановый LCD.
- **heritage** — «ретро» с янтарным LCD и почти прямыми углами (3px), двойная рамка дисплея.
- **daylight** — светлая для работы днём; `color-scheme: light`, мягкие тени, контрастные таблицы.

## Как добавить тему

1. В `web/appearance.css` добавьте блок:

   ```css
   :root[data-appearance="mytheme"] {
     --bg:#...; --panel:#...; --panel-2:#...; --line:#...;
     --text:#...; --muted:#...; --accent:#...; --accent-2:#...;
     --lcd:#...; --radius:12px;
   }
   ```

2. Добавьте ID в список `themes` в `web/appearance.js`.
3. Добавьте `<option value="mytheme">` в `<select id="optAppearance">` в `web/index.html`.
4. Обновите перевод названия в `web/lang/ru.json` / `en.json` (`opts.appearance.*`).

Компоновка и размер кнопок от темы не зависят. Новый вариант компоновки добавляется
в `layouts` (`web/appearance.js`) и описывается в CSS через `html[data-workspace="..."]`;
новый размер — через `html[data-density="..."]`.
