# Поддержка трансиверов и звука

Пульт работает в двух режимах:

| Режим (`radio_backend`) | Для чего | Что даёт |
|---|---|---|
| `native` | FTX-1 (Field / Optima) | Расширенные меню, память, цифровые модули, полный набор регуляторов |
| `hamlib` | Любой трансивер, который есть в Hamlib | Частота, вид работы, основные уровни, PTT через CAT или RTS/DTR |

## Матрица моделей

| Трансивер | Режим | Статус | Примечания |
|---|---|---|---|
| Yaesu FTX-1 | `native` | Проверено на реальном аппарате | Рекомендуемый режим, все функции пульта |
| Yaesu FT-710 | `hamlib` | Ожидается рабочим, нужен отзыв с аппаратом | Модель Hamlib `1049`, CAT-порт Enhanced |
| Yaesu FTDX10 | `hamlib` | Ожидается рабочим | Модель Hamlib `1042` |
| Yaesu FTDX101 / FT-991A / FT-891 | `hamlib` | Ожидается рабочим | PTT обычно через CAT |
| Icom (IC-7300, IC-7610 и др.) | `hamlib` | Ожидается рабочим | Нужен CI-V адрес: `-C civaddr=0x94` |
| Kenwood / Elecraft / Xiegu | `hamlib` | Ожидается рабочим | Управление через CAT, PTT через CAT или RTS |
| Любая модель из `rigctld -l` | `hamlib` | Зависит от драйвера Hamlib | Список в панели берётся из установленного Hamlib |

Физически проверен только FTX-1. Остальные модели используют стандартный Hamlib/CAT и требуют проверки на конкретном аппарате — сообщения об ошибках помогают дополнить матрицу.

## CAT-порт

1. Подключите трансивер кабелем USB (или USB–CAT адаптером).
2. В панели выберите COM-порт CAT и скорость, совпадающую с меню трансивера.
3. Для Icom укажите CI-V адрес в «Дополнительных параметрах Hamlib», например:
   `-C civaddr=0x94`
4. Для нестандартного COM-порта можно добавить:
   `-C serial_parity=N -C serial_handshake=none`

Автоопределение по CAT ID работает только для современных Yaesu. Для других
производителей модель выбирается вручную в списке Hamlib.

## PTT

Поддерживаются два способа:

* **CAT** — `ptt_method: TX1` или `TX2`; в режиме Hamlib PTT передаётся через rigctld.
* **RTS/DTR** — отдельная линия COM-порта: `ptt_method: RTS` (или `DTR`) и `ptt_port`.
  Подходит для SignaLink, RigBlaster и стандартного COM-порта Yaesu.

Если Hamlib-драйвер не умеет PTT (или возвращает ошибку `-11 / -4 / -6 / -9`),
пульт не разрывает связь: выберите RTS/DTR, и управление частотой останется
через CAT. В журнале будет подсказка.

## Звук

Вход приёма и выход передачи выбираются **отдельно**:

* USB-кодек трансивера: обычно «USB Audio CODEC» или «USB Audio Device».
* Внешняя USB-звуковая карта: вход и выход могут быть разными устройствами
  PortAudio — выберите каждое в своём списке.
* Если оставить «Автоматически», пульт подберёт USB-кодек или пару к входу.

## Windows: установщик, Hamlib и RTL-SDR

Рекомендуемый вариант — **`Yaesu-Web-Pult-Setup.exe`** из релиза `windows-latest`.
Установщик ставит программу в `C:\Program Files\Yaesu Web Pult`, сразу добавляет
Hamlib 4.7.2 и RTL-SDR, устанавливает драйверы FTDI/CP210x и Zadig для RTL-SDR.
Настройки и записи хранятся в `%LOCALAPPDATA%\Yaesu Web Pult`; приложение
запускается без прав администратора.

Портативные варианты:

* `Yaesu-Web-Pult-folder.zip` — Hamlib и RTL-SDR уже внутри;
* `Yaesu-Web-Pult.exe` — один файл, Hamlib/RTL-SDR ставятся скриптами ниже.

Для одиночного портативного EXE в релизе есть скрипты:

* `install-hamlib.ps1` — скачивает Hamlib 4.7.2 в `tools/hamlib/...`.
  Запуск: `powershell -ExecutionPolicy Bypass -File .\install-hamlib.ps1`
* `install-rtlsdr.ps1` — скачивает `rtl_sdr.exe` и DLL в `tools/rtlsdr/`.
  Запуск: `powershell -ExecutionPolicy Bypass -File .\install-rtlsdr.ps1`

После установки перезапустите программу/панель. Hamlib появится в списке моделей,
а RTL-SDR — как источник водопада (`waterfall_source=rtlsdr`). Программа ищет
`rigctld.exe` в `tools/hamlib/...`, а `rtl_sdr.exe` — в `PATH` и `tools/rtlsdr`.
Скрипты качают файлы с GitHub/osmocom, а не с ftdichip.com.

## Частые проблемы

| Симптом | Что проверить |
|---|---|
| Hamlib не запускается | `rigctld -l` работает? Установлен `libhamlib-utils` (Linux) или Hamlib для Windows? |
| Нет модели в списке | Обновите Hamlib и нажмите «Обновить модели» |
| «PTT недоступен» | Выберите RTS/DTR и отдельный COM-порт |
| Нет приёма/передачи звука | Выберите вход и выход отдельно, проверьте кабель и ↻ |
| Icom не отвечает | Проверьте CI-V адрес и скорость CI-V |
| Водопад тёмный в FM | Закрыт шумоподавитель — это нормально |

## Проверка без аппаратуры

* `hamlib_model: 1` — Hamlib Dummy: проверка интерфейса без трансивера.
* `simulate: true` — встроенный симулятор пульта.

Эти режимы не заменяют проверку CAT и звука на реальном трансивере.
