## 🎨 Как увидеть настоящие темы

1. Откройте Yaesu Web Pult
2. Перейдите в **Настройки** (⚙)
3. Нажмите **"Выбрать тему оформления"**
4. Интерактивная галерея с предпросмотром
5. Клик на тему для выбора
6. **"Применить"** для сохранения

**Темы сохраняются автоматически** и применяются при следующем запуске!
