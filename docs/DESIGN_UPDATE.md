# Новый современный дизайн Yaesu Web Pult

## Что улучшено

### 🎨 Визуальный дизайн

#### Современная цветовая палитра
- **Темная тема** оптимизирована для длительной работы
- **Акцентные цвета**: зелёный для успеха, красный для TX, cyan для LCD
- **Градиенты** добавляют глубину интерфейсу
- **Тени** создают ощущение слоёв и иерархии

#### Типография
- **Системные шрифты** для быстрой загрузки
- **Моноширинный** для частот, кодов, технических данных
- **Правильная иерархия** размеров и весов шрифтов

#### Компоненты
- **Карточки** с тенями и эффектами hover
- **Кнопки** с градиентами и анимациями
- **Поля ввода** с фокусными состояниями
- **Индикаторы** с эффектом свечения
- **Чипы** для статусной информации

### 📱 Адаптивность

#### Десктоп (>1200px)
- Сетка 2-3 колонки
- Все элементы на виду
- Оптимальное использование пространства

#### Планшет (768px - 1200px)
- Сетка 2 колонки
- Адаптивные размеры кнопок
- Компактное расположение

#### Мобильные (<768px)
- Одна колонка
- Полная ширина элементов
- Touch-friendly кнопки (минимум 42px)
- Стек вместо flex-row

### 🎯 UX улучшения

#### Визуальная обратная связь
- **Анимации** при наведении и нажатии
- **TX индикатор** пульсирует
- **Статус лампы** с эффектом свечения
- **Сохранено** - плавное появление

#### Доступность
- **Контрастные** цвета для текста
- **Достаточные** размеры кнопок
- **Понятные** метки и подсказки
- **Keyboard navigation** поддержка

#### Интуитивность
- **Иконки** для быстрого распознавания
- **Группировка** связанных настроек
- **Hints** под полями ввода
- **QR код** для мобильного доступа

### 🚀 Производительность

- **CSS-only** анимации (аппаратное ускорение)
- **Минимум JavaScript** для стилей
- **Системные шрифты** (без загрузки)
- **Оптимизированные** селекторы

### 📐 Структура

```
header
  ├─ brand (logo + title)
  ├─ actions (scale + saved indicator)

wizard (первый запуск)

hero panel
  ├─ status (lamp + title + freq)
  ├─ actions (кнопки управления)
  ├─ chips (информация)
  └─ error message

cards grid (адаптивная сетка)
  ├─ Трансивер
  ├─ Аудио
  ├─ Доступ (с QR кодом)
  ├─ Параметры
  ├─ Подключённые
  └─ Журнал

footer
  ├─ copyright
  └─ actions (quit, folder)
```

## Ключевые особенности

### Панель статуса (Hero)
- **Крупный индикатор** состояния с анимацией
- **LCD-стиль** для отображения частоты
- **Кнопки действий** всегда на виду
- **Информационные чипы** для доп. данных

### Карточки настроек
- **Группировка** по функциям
- **Иконки** для идентификации
- **Accordion** для дополнительных настроек
- **Inline валидация** (визуальная)

### Адаптивная сетка
- **Auto-fit** автоматическое размещение
- **Минимальная ширина** 340px для карточек
- **1 колонка** на мобильных
- **До 3 колонок** на больших экранах

### Темная тема
- **Комфортная** для глаз при длительной работе
- **Контрастная** для радиолюбителей (работа в темноте)
- **Профессиональная** как у радио оборудования
- **Современная** как у GitHub, VS Code

## Использование

### Текущая панель
`panel.html` - оригинальный дизайн (сохранён)

### Новая панель
`panel-modern.html` - современный дизайн

### Переключение
Переименовать файлы или обновить ссылки в server/main.py
