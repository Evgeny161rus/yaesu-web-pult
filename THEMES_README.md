## 🚀 Использование

### Интеграция в проект

#### 1. Подключить CSS в `web/index.html`

Добавьте после существующих стилей:

```html
<link rel="stylesheet" href="themes-modern.css">
<link rel="stylesheet" href="theme-selector.css">
```

#### 2. Подключить JavaScript

Добавьте перед закрывающим `</body>`:

```html
<script src="theme-selector.js"></script>
```

#### 3. Готово!

После перезагрузки страницы:
- В настройках появится кнопка **"Выбрать тему оформления"**
- Выбранная тема сохраняется автоматически
- При следующем запуске применяется сохранённая тема

## 🎯 Как выбрать тему

### Через интерфейс (рекомендуется)

1. Откройте пульт
2. Перейдите на вкладку **"Настройки"** (⚙)
3. Нажмите **"Выбрать тему оформления"**
4. Выберите тему из галереи
5. Нажмите **"Применить"**

### Программно (для разработчиков)

```javascript
// Применить тему
YaesuThemes.applyTheme('studio');

// Текущая тема
const theme = YaesuThemes.getCurrentTheme();

// Показать диалог выбора
YaesuThemes.showThemeSelector();
```

### Через консоль браузера (для тестирования)

```javascript
// Быстро переключить тему
document.documentElement.setAttribute('data-appearance', 'heritage');
```

## 🎨 Описание тем

### 🌙 Modern Dark (по умолчанию)
- **Для:** Повседневная работа
- **Цвета:** Тёмно-синий фон, циановый LCD
- **Особенности:** Современные градиенты, приятная для глаз

### 🎙 Studio
- **Для:** Профессиональное вещание
- **Цвета:** GitHub-стиль, синий LCD
- **Особенности:** Чистый профессиональный вид

### ☀️ Daylight
- **Для:** Работа при ярком освещении
- **Цвета:** Светлый фон, тёмно-синий текст
- **Особенности:** Отличная читаемость днём

### 📻 Radio Night
- **Для:** Аутентичный вид Yaesu
- **Цвета:** Чёрный фон, яркий зелёный LCD
- **Особенности:** Как настоящий трансивер

### 🕰 Heritage
- **Для:** Винтажный стиль
- **Цвета:** Коричневый фон, янтарный LCD
- **Особенности:** Тёплое ламповое свечение

### 🏕 Field
- **Для:** SOTA/POTA, полевые условия
- **Цвета:** Зелёный фон, жёлто-зелёный LCD
- **Особенности:** Естественные цвета

### 🪖 Tactical
- **Для:** Тактические операции
- **Цвета:** Оливковый фон, приглушённый зелёный
- **Особенности:** Совместимость с ночным видением

## 🔧 Для разработчиков

### Структура CSS-переменных

```css
:root {
  /* Фоны */
  --bg: #xxxxxx;
  --panel: #xxxxxx;
  --panel-2: #xxxxxx;
  
  /* Текст */
  --text: #xxxxxx;
  --text-secondary: #xxxxxx;
  
  /* LCD */
  --lcd: #xxxxxx;
  --lcd-glow: rgba(...);
  
  /* Акценты */
  --accent: #xxxxxx;
  --accent-2: #xxxxxx;
  
  /* Статусы */
  --ok: #xxxxxx;
  --warn: #xxxxxx;
  --tx: #xxxxxx;
}
```

### API

```javascript
// Доступные методы
YaesuThemes.applyTheme(themeId)
YaesuThemes.getCurrentTheme()
YaesuThemes.showThemeSelector()
YaesuThemes.themes // массив всех тем

// События
window.addEventListener('themechanged', (e) => {
  console.log('New theme:', e.detail.theme);
});
```

### Создание своей темы

1. Добавьте CSS в `themes-modern.css`:
```css
:root[data-appearance="my-theme"] {
  --bg: #xxxxxx;
  /* остальные переменные */
}
```

2. Зарегистрируйте в `theme-selector.js`:
```javascript
{
  id: 'my-theme',
  name: 'My Theme',
  description: 'Description',
  icon: '🎨',
  preview: { bg, panel, lcd, accent }
}
```
