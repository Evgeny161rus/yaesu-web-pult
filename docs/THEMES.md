# 🎨 Темы оформления Yaesu Web Pult

## Обзор

Yaesu Web Pult поддерживает 7 профессиональных тем оформления для разных условий работы и предпочтений пользователей.

## Доступные темы

### 1. 🌙 Modern Dark (по умолчанию)
**ID:** `modern`

Современная тёмная тема с циановым LCD дисплеем.

- **Фон:** Тёмно-синий (#0a0e14)
- **LCD:** Яркий циан (#4af0c8)
- **Акцент:** Зелёный (#2ea44f)
- **Применение:** Основная тема для повседневной работы
- **Особенности:** Приятная для глаз, современные градиенты, хороший контраст

**Рекомендуется для:**
- Повседневная работа в любое время суток
- Длительные эфирные сессии
- Современный стиль интерфейса

---

### 2. 🎙 Studio
**ID:** `studio`

Профессиональная студийная тема с синим акцентом.

- **Фон:** GitHub-стиль (#0d1117)
- **LCD:** Светло-синий (#79c0ff)
- **Акцент:** Яркий синий (#58a6ff)
- **Применение:** Профессиональная радиостанция, вещание
- **Особенности:** Чистый профессиональный вид, отличная читаемость

**Рекомендуется для:**
- Радиовещание и студийная работа
- Профессиональные операторы
- Контест и DX-педиции

---

### 3. ☀️ Daylight
**ID:** `daylight`

Светлая дневная тема для работы при ярком освещении.

- **Фон:** Светло-серый/белый (#f6f8fa)
- **LCD:** Тёмно-синий (#0550ae)
- **Акцент:** Синий (#0969da)
- **Применение:** Дневная работа, яркое освещение
- **Особенности:** Отличная читаемость при дневном свете, меньше нагрузка на глаза

**Рекомендуется для:**
- Работа при дневном освещении
- Уличные/полевые условия днём
- Пользователи, предпочитающие светлые интерфейсы

**Рекомендуется для:**

## Использование

### Выбор темы через интерфейс

1. Откройте пульт Yaesu Web Pult
2. Перейдите на вкладку **«Настройки»** (⚙)
3. Нажмите кнопку **«Выбрать тему оформления»**
4. Выберите понравившуюся тему из галереи
5. Нажмите **«Применить»**

### Программный выбор темы

```javascript
// Применить тему
YaesuThemes.applyTheme('studio');

// Получить текущую тему
const current = YaesuThemes.getCurrentTheme();

// Показать диалог выбора темы
YaesuThemes.showThemeSelector();

// Список всех тем
const themes = YaesuThemes.themes;
```

### Автоматическое сохранение

Выбранная тема сохраняется в `localStorage` браузера и автоматически применяется при следующем запуске пульта.

## Интеграция в проект

### Подключение CSS

Добавьте в `index.html`:

```html
<link rel="stylesheet" href="themes-modern.css">
<link rel="stylesheet" href="theme-selector.css">
```

### Подключение JavaScript

Добавьте в `index.html`:

```html
<script src="theme-selector.js"></script>
```

### Применение темы

Темы работают через атрибут `data-appearance` на элементе `<html>`:

```html
<!-- Modern Dark (по умолчанию) -->
<html>

<!-- Studio -->
<html data-appearance="studio">

<!-- Daylight -->
<html data-appearance="daylight">

<!-- Radio Night -->
<html data-appearance="radio-night">

<!-- Heritage -->
<html data-appearance="heritage">

<!-- Field -->
<html data-appearance="field">

<!-- Tactical -->
<html data-appearance="tactical">
```

## Создание собственной темы

### 1. Определите цветовую палитру

```css
:root[data-appearance="my-theme"] {
  /* Фоны */
  --bg: #xxxxxx;
  --panel: #xxxxxx;
  --panel-2: #xxxxxx;
  --panel-3: #xxxxxx;
  
  /* Границы */
  --line: #xxxxxx;
  --line-subtle: #xxxxxx;
  --line-strong: #xxxxxx;
  
  /* Текст */
  --text: #xxxxxx;
  --text-secondary: #xxxxxx;
  --text-tertiary: #xxxxxx;
  --muted: #xxxxxx;
  
  /* Акценты */
  --accent: #xxxxxx;
  --accent-2: #xxxxxx;
  --accent-hover: #xxxxxx;
  
  /* LCD */
  --lcd: #xxxxxx;
  --lcd-glow: rgba(xxx, xxx, xxx, 0.2);
  --lcd-shadow: 0 0 12px rgba(xxx, xxx, xxx, 0.3);
  
  /* Статусы */
  --ok: #xxxxxx;
  --warn: #xxxxxx;
  --tx: #xxxxxx;
  --tx-glow: rgba(xxx, xxx, xxx, 0.4);
  
  /* Эффекты */
  --radius: 10px;
  --radius-lg: 14px;
  
  color-scheme: dark; /* или light */
}
```

### 2. Добавьте тему в список

Отредактируйте `theme-selector.js`:

```javascript
{
  id: 'my-theme',
  name: 'Моя тема',
  description: 'Описание моей темы',
  icon: '🎨',
  preview: {
    bg: '#xxxxxx',
    panel: '#xxxxxx',
    lcd: '#xxxxxx',
    accent: '#xxxxxx'
  }
}
```

### 3. Добавьте специфичные стили (опционально)

```css
/* Специальные эффекты для вашей темы */
:root[data-appearance="my-theme"] .freq {
  /* Уникальные стили для частоты */
}
```

## Технические детали

### CSS переменные

Все темы используют единый набор CSS-переменных, определённых в `:root`. Это обеспечивает:
- Единообразие компонентов
- Лёгкое переключение тем
- Плавные переходы между темами

### Производительность

- **GPU-ускоренные анимации** через `transform` и `opacity`
- **Плавные переходы** 0.3s для комфортной смены тем
- **Оптимизированные селекторы** без избыточной вложенности

## FAQ

**Q: Как вернуться к стандартной теме?**  
A: Выберите тему "Modern Dark" в селекторе тем.

**Q: Сохраняется ли тема после перезагрузки браузера?**  
A: Да, выбранная тема сохраняется в localStorage.

**Q: Можно ли переключать темы горячими клавишами?**  
A: В текущей версии нет, но можно добавить в будущем обновлении.

**Q: Как тема влияет на производительность?**  
A: Минимально. Все анимации аппаратно ускорены, смена темы занимает ~0.3с.

**Q: Какая тема лучше для длительной работы?**  
A: Modern Dark или Studio для ночи, Daylight для дня.

**Q: Можно ли автоматически переключать тему по времени суток?**  
A: В текущей версии нет, но это планируется в будущих обновлениях.

**Q: Работают ли темы на мобильных устройствах?**  
A: Да, все темы полностью адаптивны и работают на всех устройствах.
