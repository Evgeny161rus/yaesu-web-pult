## 🚀 Как использовать

### Панель управления (panel-modern.html)

#### Вариант 1: Переименовать
```bash
cd C:/Users/bayan/AppData/Local/Temp/opencode/ftx1-pult/ftx1-pult/web
move panel.html panel-old.html
move panel-modern.html panel.html
```

#### Вариант 2: Изменить ссылку в server/main.py
```python
# Найти строку:
panel_url = 'http://localhost:%d/panel.html' % cfg['http_port']

# Заменить на:
panel_url = 'http://localhost:%d/panel-modern.html' % cfg['http_port']
```

### Темы основного пульта

#### 1. Подключить в web/index.html

После `<link rel="stylesheet" href="appearance.css">` добавить:

```html
<link rel="stylesheet" href="themes-modern.css">
<link rel="stylesheet" href="theme-selector.css">
```

Перед `</body>` добавить:

```html
<script src="theme-selector.js"></script>
```

#### 2. Готово!

После перезагрузки пульта:
- В настройках появится кнопка "Выбрать тему оформления"
- Выбранная тема сохраняется автоматически
- 7 тем доступны сразу
