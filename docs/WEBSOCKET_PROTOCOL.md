# WebSocket протокол FTX-1 Пульт

## Обзор

Пульт использует WebSocket для двунаправленной связи между браузером и сервером. Протокол поддерживает как текстовые (JSON), так и бинарные сообщения.

## Подключение

```
ws://localhost:8080/ws  - локальное подключение (HTTP)
wss://IP:8443/ws        - удалённое подключение (HTTPS)
```

## Типы сообщений

### Текстовые (JSON)

Все JSON сообщения имеют поле `t` (тип).

#### От клиента к серверу

**Авторизация:**
```json
{
  "t": "hello",
  "pw": "пароль",
  "rate": 16000
}
```
- `pw`: пароль (необязательно для локального подключения)
- `rate`: частота аудио (8000, 16000 или 48000 Гц)

**Управление частотой:**
```json
{
  "t": "set",
  "k": "freq_a",
  "v": 14074000
}
```

**PTT (передача):**
```json
{
  "t": "ptt",
  "on": true
}
```

**Подтверждение PTT (каждые 500мс при передаче):**
```json
{
  "t": "ptt_alive"
}
```

**CAT команда:**
```json
{
  "t": "raw",
  "c": "FA;"
}
```

**Запрос спектра:**
```json
{
  "t": "spectrum_get"
}
```

#### От сервера к клиенту

**Успешная авторизация:**
```json
{
  "t": "hello_ok",
  "local": true,
  "version": "3.2-preview",
  "backend": "native",
  "running": true,
  "max_tx": 180
}
```

**Состояние трансивера:**
```json
{
  "t": "state",
  "s": {
    "freq_a": 14074000,
    "mode": "USB",
    "tx": false,
    "connected": true
  },
  "full": false
}
```
- `full`: true при полном обновлении, false при изменениях

**Уведомление:**
```json
{
  "t": "note",
  "msg": "Текст сообщения"
}
```

**Уровни аудио:**
```json
{
  "t": "lv",
  "rx": 0.234,
  "tx": 0.0
}
```

**Информация о PTT:**
```json
{
  "t": "ptt_owner",
  "you": false,
  "busy": true,
  "who": "192.168.1.100:54321"
}
```

### Бинарные сообщения

Первый байт - маркер типа данных.

#### Аудио RX (сервер → клиент)

```
Байт 0: 0x01
Байты 1+: PCM signed int16 little-endian
```

Частота дискретизации соответствует запрошенной в `hello` (8000/16000/48000 Гц).

#### Водопад (сервер → клиент)

```
Байт 0: 0x02
Байты 1-2: количество точек (uint16 LE)
Байты 3-6: bin_hz (float32 LE)
Байты 7+: уровни (int8, dBFS * 2)
```

#### Аудио TX (клиент → сервер)

```
Байт 0: 0x03
Байт 1: частота (1=8kHz, 2=16kHz, 6=48kHz)
Байты 2+: PCM signed int16 little-endian
```

Старый формат (без байта частоты):
```
Байт 0: 0x03
Байты 1+: PCM signed int16 little-endian
```

## Административные сообщения

Доступны только при локальном подключении.

**Запрос статуса:**
```json
{
  "t": "admin_hello"
}
```

**Ответ:**
```json
{
  "t": "admin_init",
  "cfg": {...},
  "ports": [...],
  "audio": [...],
  "version": "3.2-preview"
}
```

**Запуск/остановка:**
```json
{"t": "admin_start"}
{"t": "admin_stop"}
```

**Сохранение настроек:**
```json
{
  "t": "admin_save",
  "cfg": {
    "cat_port": "COM3",
    "cat_baud": 38400
  }
}
```

## Цифровые режимы

### CW (телеграф)

```json
{
  "t": "cw_tx",
  "text": "CQ DE R6AAF K"
}
```

### FT8

```json
{
  "t": "ft_call",
  "call": "DL1ABC",
  "grid": "JO62"
}
```

### RTTY

```json
{
  "t": "rt_tx",
  "text": "CQ CQ DE R6AAF"
}
```

## Обработка ошибок

При ошибке сервер отправляет:
```json
{
  "t": "note",
  "msg": "Описание ошибки"
}
```

Критичные ошибки (потеря связи с трансивером):
```json
{
  "t": "state",
  "s": {"connected": false}
}
```

## Защита

- Локальное подключение (127.0.0.1) не требует пароля
- Удалённое подключение требует пароль в поле `pw` сообщения `hello`
- После 3 неверных попыток задержка увеличивается до 5 секунд
- Проверка Origin для предотвращения CSRF
- PTT автоматически снимается через 1.5с без подтверждений
- Максимальное время передачи ограничено (по умолчанию 180с)

## Примеры

### Настройка частоты

```javascript
ws.send(JSON.stringify({
  t: 'set',
  k: 'freq_a',
  v: 7074000
}));
```

### Переключение режима

```javascript
ws.send(JSON.stringify({
  t: 'set',
  k: 'mode',
  v: 'USB'
}));
```

### Передача с PTT

```javascript
// Включить PTT
ws.send(JSON.stringify({t: 'ptt', on: true}));

// Отправлять аудио
const pcm = new Int16Array([...]); 
ws.send(new Uint8Array([0x03, 2, ...new Uint8Array(pcm.buffer)]));

// Поддерживать PTT
setInterval(() => {
  ws.send(JSON.stringify({t: 'ptt_alive'}));
}, 500);

// Выключить PTT
ws.send(JSON.stringify({t: 'ptt', on: false}));
```
