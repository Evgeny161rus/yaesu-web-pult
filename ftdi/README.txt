Папка для библиотек FTDI (USB-scope FT4222, FT-710 / FTDX10 / FTDX101).

Библиотеки не входят в поставку (распространяются FTDI отдельно). Скачайте их и положите сюда,
чтобы Yaesu Web Pult нашёл их автоматически (пути в настройках можно оставить пустыми).
Также можно включить в настройках опцию «Автоматически скачивать библиотеки FTDI…» или нажать
кнопку загрузки в панели — программа попробует скачать файлы с сайта FTDI сама (нужен интернет;
адреса загрузки могут устареть, тогда скачайте вручную).

Скачать:
- LibFT4222: https://ftdichip.com/software-examples/ft4222h-software-examples/
- D2XX:      https://ftdichip.com/drivers/d2xx-drivers/

Какие файлы положить (для вашей ОС/архитектуры):
- Windows x64:  LibFT4222-64.dll  и  ftd2xx.dll
- Linux x86_64: libft4222.so      (и libftd2xx.so при необходимости)
- Raspberry Pi (ARM64/aarch64): libft4222.so из сборки build-arm-v8 (и libftd2xx.so при необходимости)

Важно: на Raspberry Pi нужны именно ARM64-библиотеки, x86/x64 не подойдут.
После добавления файлов перезапустите подключение к трансиверу/сервис.
Широкий водопад экспериментальный и на реальном оборудовании пока не проверялся; при ошибках будет использован обычный звуковой водопад.
