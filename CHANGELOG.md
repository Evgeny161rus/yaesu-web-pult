# Changelog

Все значимые изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [3.2-preview] - 2026-11-19

### Переименование проекта

**FTX-1 Пульт → Yaesu Web Pult**

Проект теперь универсальный пульт для различных трансиверов Yaesu, не только FTX-1.

### Удалено

#### Функции локального ИИ
- Удалена интеграция с LM Studio для совместимости с Raspberry Pi
- Удалены AI endpoints из сервера
- Удалены конфигурационные параметры `ai_*`
- Удалён модуль `server/ai.py`

**Причина**: Языковые модели требуют мощное оборудование (8+ GB RAM, GPU).
Несовместимо с целевым использованием на Raspberry Pi и бюджетных мини-ПК.

#### Архитектура и код
- **Модульная структура**: Выделены отдельные модули для улучшения maintainability
  - `constants.py` - централизация всех констант и магических чисел
  - `station.py` - основная логика управления станцией
  - `network_utils.py` - сетевые утилиты (SSL, автозапуск, IP)
  - `device_utils.py` - работа с COM-портами и аудио устройствами
- **Улучшенная типизация**: добавлены type hints для основных модулей
- **Расширенное тестирование**: новые тесты для модулей utils и констант (11 тестов)
- **CI/CD пайплайн**: 
  - `lint.yml` - проверка качества кода (flake8, pylint, mypy)
  - `tests.yml` - автоматическое тестирование на Python 3.11-3.13, Windows/Linux
- **Docker поддержка**: 
  - `Dockerfile` с multi-stage build
  - `docker-compose.yml` для быстрого развёртывания
  - Health checks и resource limits

#### Документация
- `docs/WEBSOCKET_PROTOCOL.md` - полная документация WebSocket протокола
- `docs/ARCHITECTURE.md` - детальное описание архитектуры проекта
- `docs/DOCKER.md` - руководство по Docker развёртыванию
- `CONTRIBUTING.md` - руководство для разработчиков
- `CHANGELOG.md` - история изменений

#### Инфраструктура
- `requirements.lock` - точные версии зависимостей для воспроизводимых сборок
- `.flake8` - конфигурация линтера
- `pytest.ini` - настройки тестирования
- Улучшенный `.gitignore` с полным покрытием Python-проектов

### Изменено

- **CW режим**: теперь работает полностью без ИИ
  - Автоответ по шаблонам вместо генерации ИИ
  - Разбор принятого по правилам Q-кодов
  - Декодер работает как и раньше (встроенный DSP)

- **RTTY, NAVTEX**: убраны функции перевода через ИИ
  - Весь функционал декодирования сохранён
  - Работает на любом оборудовании

### Добавлено
- Поддержка Hamlib для других трансиверов Yaesu
- Темы оформления: Radio Night, Radio Silver
- USB-спектр FT-710 (экспериментально)
- Транспорт FT4222 для FT-710
